# Moonshot Minds Tech - Next.js Website

## Setup करण्याच्या Steps:

### 1. Dependencies Install करा
```bash
npm install
```

### 2. Development Server Start करा
```bash
npm run dev
```

### 3. Browser मध्ये उघडा
```
http://localhost:3000
```

## Pages:
- `/` - Home
- `/about` - About
- `/services` - Services & Solutions
- `/why-us` - Why Partners Choose Us
- `/technologies` - Tech Stack
- `/industries` - Industries
- `/contact` - Contact

## Tech Stack:
- **Next.js 14** (App Router)
- **Tailwind CSS v3**
- **TypeScript**
- **Lucide React** (Icons)

## Color Palette:
- Primary: `#0EA5E9` (Sky Blue)
- Navy: `#0F172A`
- Background: `#F0F9FF`
